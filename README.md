# Lavin Store (فروشگاه لاوین)

پروتوتایپ و مستندات طراحی یک فروشگاه آنلاین پوشاک مردانه و زنانه با برند «لاوین».

## اهداف پروژه
- ارائه لباس زنانه و مردانه با کیفیت
- تجربه خرید آنلاین ساده و امن
- مدیریت سفارش‌ها و موجودی

## ساختار مستندات
- Personas.md — پرسوناهای کاربران
- UserStory.md — داستان‌های کاربر
- Use case diagrams/ — دیاگرام موارد استفاده
- Activity Diagrams/ — دیاگرام فعالیت
